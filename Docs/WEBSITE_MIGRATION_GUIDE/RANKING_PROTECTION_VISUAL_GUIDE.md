# Ranking Protection Visual Guide

## How Signal Protection Works

```mermaid
flowchart LR
    A["Legacy URL with history and backlinks"] --> B["301 redirect or legacy resolver"]
    B --> C["Equivalent new or archive destination"]
    C --> D["Canonical plus hreflang plus crawlable links"]
    D --> E["Google and Bing can reassign signals more safely"]
```

## How File Protection Works

```mermaid
flowchart LR
    A["Old PDF or document URL"] --> B["Recovered file or stable replacement file URL"]
    B --> C["Permanent redirect"]
    C --> D["Backlinks and search entry points are preserved better"]
```

## How Webometrics Protection Works

```mermaid
flowchart TD
    A["Single strong institutional domain"] --> B["Research, profile, archive, and file pages remain public"]
    B --> C["External visibility and scholarly discoverability stay stronger"]
    C --> D["Better support for Visibility, Transparency, and Excellence"]
```

## The Main Message

Rankings do not survive a migration because the new site is attractive.

They survive more safely when the university protects the signals that already exist.
