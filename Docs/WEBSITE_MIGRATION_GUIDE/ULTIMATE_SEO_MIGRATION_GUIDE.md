# Ultimate SEO Migration Guide
## The Shortest Professional Version Of The Plan

If someone reads only one file, let it be this one.

## The One-Sentence Strategy

Preserve old public value first, then launch the new platform only when URLs, files, language signals, and monitoring are ready.

## The Ten Decisions That Matter Most

1. Keep the institutional domain unless a move is truly necessary.
2. Do not combine unnecessary domain, structure, and design changes on the same day.
3. Give every valuable old URL one best destination.
4. Use permanent redirects for permanent moves.
5. Keep those redirects live for at least one year.
6. Preserve key PDFs, archives, and research visibility.
7. Keep Arabic and English versions technically clear through canonical and `hreflang` rules.
8. Put only canonical URLs in the long-term sitemap set.
9. Launch only with real monitoring in Google Search Console and Bing Webmaster Tools.
10. Do not replace valuable out-of-scope content with thin placeholders.

## The One Thing To Understand About Webometrics

As verified on `2026-04-21`, the official methodology emphasizes:

- Visibility
- Transparency
- Excellence

This means SPU should protect:

- its institutional domain strength
- public discoverability of research and profile content
- openness and stability of academic material

It does not mean publishing random files for file count.

## The One Thing To Understand About Google

Google needs clear evidence that old public URLs now live at valid new destinations.

That evidence comes from:

- redirects
- canonicals
- `hreflang`
- sitemaps
- crawlable links
- consistent monitoring

## The One Thing To Understand About This Repository

The current Laravel project is still a foundation-stage build.

It is not yet a full public replacement for the old SPU website.

Therefore the safe path is:

- build current-scope pages properly
- preserve the rest through archive or continuity support
- cut over only when release gates are met
